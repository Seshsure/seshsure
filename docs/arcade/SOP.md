# SOP: SeshSure White-Label Arcade Program
**Owner:** Rob (Founder) | **Last Updated:** July 2026 | **Review Cadence:** Quarterly (monthly during first 2 producer launches)

## Purpose
Defines the end-to-end process for onboarding a producer onto the SeshSure Arcade platform — from order intake through print, activation, and live hunt operations — so every producer launch runs identically, no game-breaking mistakes reach customers, and SeshSure's platform standards are enforced at every step.

## Non-Negotiables (stated on every order form and contract)
1. **SeshSure materials only.** All peels printed on SeshSure stock with food-contact-safe adhesive, applied at SeshSure's facility. Cones ship finished. No sticker rolls leave the building. No exceptions.
2. **No overage in circulation.** Print overs are reconciled, codes voided in the registry, and destroyed with a signed destruction log.
3. **Live hunts are locked.** No sentence, tier, or odds edits after launch. Draft → Launch (locked) → End (declared outcome) → Archive.
4. **All custom words pass SeshSure print-fit review.** Length ≤ 12 characters, readable at peel size, shelf-safe. SeshSure has final veto. No escalation path.
5. **"Powered by SeshSure" badge** remains on every white-label arcade. Producer branding sits on top of the SeshSure background — never replaces it.

## Process Flow
ORDER FORM → REVIEW GATE → REGISTRY → PRINT GATE → APPLY GATE → PACK GATE → SHIP → ACTIVATE GATE → BRAND SETUP → HUNT LIVE
Each GATE must reconcile against the registry before the next stage starts. Any variance = full stop, Rob notified same day.

## Key Steps (condensed — full detail in program spec)
1. **Order:** artwork on dieline, word list, mix, tier counts + picks (or SeshSure assigns), optional hunt sentence, qty in 800-packs, 1-cone/3-cone retail, ship-to, needed-by, sale states. No prize fields — prizes are producer's business.
2. **Review (≤2 biz days):** print-fit, dieline, sentence-words-exist-in-mix, state compliance, tier sanity. One consolidated revision request, no partial approvals.
3. **Registry:** one row per peel — code, word, category, tier, batch, producer, pack/roll sequence (per-pack seeding: glue words + a verb per retail pack), golden placed randomly by system (no human sees position). Checksum recorded.
4. **Print Gate:** 100-peel proof physically peeled + sandbox-redeemed 100/100. First/last codes per roll scan-verified. Overage returned, voided, signed destruction log.
5. **Apply Gate (SeshSure facility):** rolls in sequence, end count vs registry, damaged-unit log. Variance = stop.
6. **Pack Gate:** retail packs → 800-pack cases in registry order; case label = producer ID + batch + code range + ONE case activation code; label scan must match order before sealing.
7. **Ship:** carrier scans; lost/stolen = void range (codes never activated = worthless), reprint.
8. **Activate:** producer scans case code on receipt; only then do that case's peel codes go live.
9. **Hunt Lifecycle:** Draft (composer validates every word against PRINTED inventory, shows scarcity) → Launch (locks) → Live (no edits ever) → End (declared outcome; backup drawing if golden unclaimed per published rules) → Archive (public proof of payout).
10. **Payout Verify:** physical peels + codes on claimant's account + registry/peel-image match. All three or no payout.

## Exceptions
| Scenario | Action |
|---|---|
| Word fails print-fit | Veto with reason + nearest compliant alternative. Final. |
| Sentence word not in printed run | Composer blocks launch. Revise or supplemental run. |
| Golden unclaimed at end | Published backup rule executes. Never extend silently. |
| Case lost/stolen | Void range, reprint, file with carrier. |
| Gate variance | Full stop, reconcile, Rob same day. |
| Edit-live-hunt request | Refuse. End with outcome, launch new. |
| Suspicious duplicate code | Freeze, pull history, check activation chain first. |
| Producer churns with live codes | Redeemable through published end dates; no new hunts; arcade read-only after last archive. |

## Metrics
Order→ship ≤3wk · gate variances 0 · proof 100/100 · batch redemption ≥40%/90d · reorder ≥60%/6mo · disputed payouts 0

## Compliance
Counsel-reviewed Sweepstakes Official Rules doc attached at CLIENT APPROVAL time (never a launch blocker later). Free-entry (no-purchase) path with genuine odds at all tiers must exist before any prize hunt goes live.
